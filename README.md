# Bayt Al Hijab React Project

This is a Vite + React split of the uploaded single-file component.

## Structure

- `src/App.jsx` – main app shell and state
- `src/styles.css` – all styles extracted from the inline CSS
- `src/data/products.js` – product data
- `src/data/constants.js` – categories, WhatsApp number, testimonials
- `src/utils/whatsapp.js` – WhatsApp URL helper
- `src/components/*` – reusable UI pieces

## Run

```bash
npm install
npm run dev
```

Replace the WhatsApp number in `src/data/constants.js` with the real one before going live.
